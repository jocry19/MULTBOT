MULT Q2 - Perpetual Signal Bot (Paper-Trading, maximaler Hebel)
===============================================================

KAPITAL: unbegrenzt. Jede Position bekommt 100 USD Margin x Maximalhebel
(z.B. 10x -> 1.000 USD, BTC 40x -> 4.000 USD), beliebig viele gleichzeitig.
Die Kandidaten jeder 5-Minuten-Bar werden nach erwarteter Rendite auf die
Margin gerankt (Bewegung x Hebel - Kosten); genommen werden die besten, die
nach Kosten im Plus erwartet werden.
Gemessen wird der PnL in USD (realisiert + offen) - kein Kontostand, der
limitiert, kein Totalverlust. Einstellbar in config.yaml unter "account".

WIE ER ENTSCHEIDET (Standard: "Marktsprache"): keine festen Strategien.
Jede Bar wird zu einem Wort (Bewegung x Volumen x Spanne), dazu die
Stimmung aller Maerkte und der Verlauf der letzten Stunde. Der Bot lernt
live, was auf welche Woerter folgt, und vergisst Altes wieder. Seite F12
("SPRACHE") zeigt, was er gerade liest. Zurueck zum alten Verfahren:
in config.yaml  signal: mode: ensemble

UPDATE VON MULTBOT: Diesen Ordner neben den alten MULTBOT-Ordner legen.
Beim ersten Start uebernimmt MULT Q2 automatisch Konto, offene Positionen
und Trades von dort (der alte Ordner bleibt unveraendert).

SO STARTEST DU DEN BOT
----------------------
Windows:  Doppelklick auf  MULT-Q2.bat
          (Kommt "Der Computer wurde durch Windows geschuetzt": "Weitere
          Informationen" -> "Trotzdem ausfuehren".)
macOS:    Rechtsklick auf  MULT-Q2.command  -> "Oeffnen" (nur beim ersten Mal,
          danach reicht ein Doppelklick)
Linux:    ./start.sh

Beim ersten Start richtet sich alles selbst ein (1-3 Minuten, Internet noetig):
- Ist kein Python 3.10+ vorhanden, wird es automatisch installiert
  (ueber das offizielle Tool "uv", ohne Admin-Rechte).
- Auf dem Desktop erscheint ein Icon "MULT Q2" - damit startest du kuenftig.

Danach oeffnet sich das MULT-Q2-Terminal als eigenes App-Fenster.
Das schwarze Konsolenfenster zeigt das Protokoll - schliessen = Bot beenden.

Simulation statt Live:   MULT-Q2.bat sim   bzw.  ./start.sh sim
Auf dem Handy (WLAN):    MULT-Q2.bat run --lan  -> Adresse aus dem Protokoll
                         im Handy-Browser oeffnen

Bedienung im Terminal: Kommandozeile oben rechts, z.B. "GEV <GO>", "LRN", "RES",
oder die Tasten F1-F12 (F11 = Alpha-Labor, F12 = Sprache). "HELP" zeigt alle Kommandos.

WICHTIG: Reine Simulation. Es werden keine echten Orders gesendet und kein
Geld bewegt. Keine Anlageberatung.
